10 Linux websites

  • ExplainShell – splits a shell command into parts and explains each flag from the man pages.
  • ShellCheck – checks shell scripts for bugs, quoting errors and risky patterns.
  • cheat.sh – short command examples, usable from the terminal with curl.
  • Webminal – free Linux terminal in the browser for practice.
  • Repology – compares package versions across Linux distros.
  • DistroSea – try Linux distros live in your browser before installing.
  • Flathub – app store for Flatpak apps that run on any distro.
  • ProtonDB – user reports on how Windows games run on Linux via Proton.
  • Arch Wiki – detailed Linux docs that help on any distro.
  • Linux Journey – free step-by-step course on Linux basics.
